# Портфолио Павла Анцибора

Веб-презентация 16:9: обложка, семь проектов и контакты.

Открыть: https://paulos99.github.io/portfolio-deck/

Листать: стрелки, пробел, PageUp/PageDown, Home/End, клик или свайп. У каждого слайда своя ссылка: `#1` … `#9`.

## Как устроено

- `index.html` — сцена 1920×1080, вписывается в любое окно.
- `js/slides.js` — данные слайдов: тексты, цвета, шрифты, видео. Новый кейс добавляется сюда одним объектом.
- `js/deck.js` — сборка слайдов, навигация и общий переход.
- `css/deck.css` — оформление.
- `assets/` — шрифты, логотипы, демо-записи и постеры.

Демо-записи сняты с публичных страниц и учебных стендов, на боевых сервисах ничего не менялось.
